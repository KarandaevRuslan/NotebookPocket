# NotebookPocket branding

## App icon

Original, project-specific icon artwork: `docs/brand/notebookpocket-icon.png` (1024×1024). The visual identity combines a paper notebook, a code cell, a reactive data trace and an interactive slider on an indigo/cyan/violet palette. No Observable or Acode wordmarks are used.

Android launchers use adaptive icon declarations in `app/src/main/res/mipmap-anydpi-v26` with a simplified, scalable foreground (`drawable/ic_launcher_foreground.xml`) and gradient background (`drawable/ic_launcher_background.xml`). A themed monochrome foreground remains available. Legacy density mipmap PNGs are included for launcher compatibility.

Marketing icon and social preview assets are in `docs/brand/`. Social preview is sized 1280×640 for GitHub's repository settings.

## Color and usage

- Indigo: `#151A57`
- Bright cyan: `#17C9D1`
- Violet: `#7965E8`
- Paper: `#FFFDF6`

Use a clear margin and do not replace the name with a third-party trademark. This is **independent app artwork**, not an official icon for Acode or Observable Notebook Kit.
